### 👋 Hi, I'm Juwon

Full-stack engineer from Nigeria with 6+ years of shipping production software. These days I'm a **founder who still writes every line**: I design, build and run whole products on **Rails 8 + Hotwire**, with the **Solid trio on PostgreSQL** (no Redis) and **Hotwire Native** for the mobile apps, deployed with Hatchbox to a single Hetzner box.

**🎯 Focus for 2026:** growing Brethreign, and giving back to the Rails ecosystem that lets one person build like a team.

### 🚀 What I've shipped this year

| | Product | What it is |
|---|---|---|
| 🌿 | **[Brethreign](https://brethreign.com)** | A social space and professional network for kind conversations about work, life and faith. Feed, rooms, messaging, voice notes, full-text search, the whole Bible built in, share cards and thread videos. **Web, Android & iPhone** from one Rails codebase. |
| 📜 | **[BiblioRata](https://bibliorata.com)** | A Bible study and church projection app used live in services: offline-first projection, a preaching console, reading plans and audio. |
| 🧾 | **[RezumFit](https://rezumfit.com)** | An AI career platform: résumé tailoring and ATS scoring, built on Rails 8 with LLM pipelines. |
| 🧰 | **[RailsAI Kit](https://saasrailskit.com)** | A commercial AI SaaS starter for Rails, productised and sold end to end. |
| 🏢 | **[tenant_kit](https://github.com/wintan1418/tenant_kit)** | An open-source Ruby gem for row-level multi-tenancy in Rails, strict by default, with tenant propagation into background jobs. |

### 🛠️ Open source

**Ruby on Rails:** 2 merged PRs ([#59946](https://github.com/rails/rails/pull/59946), [#59947](https://github.com/rails/rails/pull/59947)).

**Solid Queue:** 8 merged PRs, mostly reliability fixes:
- Replace terminated forks even when the database is down ([#781](https://github.com/rails/solid_queue/pull/781))
- Stop processes whose heartbeats keep failing ([#778](https://github.com/rails/solid_queue/pull/778))
- Surface the error in `fail_many_claimed` events so apps can recover ([#779](https://github.com/rails/solid_queue/pull/779))
- Document that `retry_on` can't catch process-death errors ([#789](https://github.com/rails/solid_queue/pull/789))
- Docs for dynamic recurring tasks, plus flaky-test fixes ([#777](https://github.com/rails/solid_queue/pull/777), [#775](https://github.com/rails/solid_queue/pull/775), [#776](https://github.com/rails/solid_queue/pull/776), [#782](https://github.com/rails/solid_queue/pull/782))
